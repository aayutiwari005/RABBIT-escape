# 🐇 Catch the Valorous Rabbit

> **Run. Jump. Eat. Escape. Survive.**

**Catch the Valorous Rabbit** is a fast-paced browser game where a brave rabbit tries to escape from a pursuing creature while collecting carrots along the way.

The rabbit must keep moving, jump over obstacles, collect carrots, and avoid getting caught. Every carrot gives the rabbit a small speed boost, making the game progressively faster and more challenging.

## 🎮 Game Overview

The goal is simple:

**Help the rabbit escape for as long as possible.**

The rabbit continuously tries to get away from the creature. While escaping, carrots appear in the game world. Collecting a carrot increases the rabbit's movement speed slightly.

However, if the rabbit touches an obstacle or other interactive object, its boosted movement can stop, giving the player another chance to manage the escape.

The combination of **movement, jumping, carrot collection, speed progression, and collision detection** creates an arcade-style survival experience.

## 🕹️ How to Play

1. Start the game.
2. Control the rabbit.
3. Jump when necessary to avoid obstacles.
4. Collect carrots whenever possible.
5. Each carrot increases the rabbit's speed slightly.
6. Keep escaping from the creature.
7. Avoid collisions that can interrupt the rabbit's movement.
8. Try to survive and achieve the best run possible.

## 🥕 Carrot Speed System

Carrots are more than collectibles.

Whenever the rabbit collects a carrot:

```text
Carrot Collected
       ↓
Rabbit Speed Increases
       ↓
Escape Becomes Faster
       ↓
Game Becomes More Challenging
```

The speed increase is intentionally small, allowing the difficulty to build progressively instead of changing suddenly.

## ⚙️ Core Game Mechanics

### Rabbit Movement

The rabbit is the main playable character and is responsible for escaping the pursuing creature.

### Jumping

Jumping allows the rabbit to avoid obstacles and maintain its escape.

### Carrots

Carrots act as speed-boost collectibles.

```text
Collect Carrot → +Speed → Faster Rabbit
```

### Collision

When the rabbit comes into contact with certain objects, its movement state can be affected. This provides an additional gameplay challenge and prevents the speed system from being completely uncontrolled.

### Pursuing Creature

The creature creates the main pressure of the game. The player must continuously manage the rabbit's movement and avoid being caught.
